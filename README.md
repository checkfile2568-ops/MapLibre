# ระบบบริหารเขตพื้นที่งานส่งหมาย — Version 5

ระบบเว็บแบบ Static สำหรับศาลจังหวัดลพบุรี ใช้กำหนดผู้รับผิดชอบงานส่งหมายราย
อำเภอ/ตำบล กำหนดยอดรายพื้นที่ และเผยแพร่ผลบนหน้าจอแสดงผลแบบอ่านอย่างเดียว

| หน้า | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| หน้าตั้งค่าระบบ | `index.html` | มอบหมายพื้นที่ กำหนดยอด บันทึกขึ้นส่วนกลาง ออกรายงาน |
| หน้าจอแสดงผล | `view.html` | ดูภาพรวม ค้นหา อ่านอย่างเดียว เปิดค้างบนจอได้ |

---

## มีอะไรใหม่ใน Version 5

**1. ยอดเป็น “จำนวน” ไม่ใช่จำนวนเงินอีกต่อไป**
ทุกที่ในระบบแสดงยอดเป็นตัวเลขล้วน ไม่มีคำว่าบาทหรือสัญลักษณ์ ฿ แล้ว
(การนำเข้าไฟล์เก่าที่มีคำว่า “บาท” ติดมายังอ่านได้ตามปกติ)
ผู้ดูแลเปิด/ปิดการแสดงยอดบนหน้าจอแสดงผลได้จากสวิตช์ **“แสดงยอดในหน้าจอแสดงผล”**
และผู้ที่เปิดดูยังปิดป้ายยอดเฉพาะเครื่องตัวเองได้อีกชั้นหนึ่ง

**2. ธีมใหม่ สลับสว่าง/มืดได้**
ปุ่มมุมขวาบนสลับได้ 3 สถานะ — ตามระบบ · สว่าง · มืด และจำค่าไว้ในเครื่อง
สีทั้งหมดอยู่ใน `tokens.css` ที่เดียว รวมถึงสีบนตัวแผนที่ซึ่งเปลี่ยนตามธีมด้วย

**3. แผนที่ชุดเดียวกันทั้งสองหน้าจอ**
โค้ดแผนที่ย้ายมารวมที่ `map-engine.js` ทั้งหมด สองหน้าจึงได้สี ป้าย มุมกล้อง
และการเคลื่อนไหวเหมือนกันทุกประการ พร้อมลำดับเปิดตัวแบบค่อย ๆ ไล่เข้า
(ทั้งประเทศ → จังหวัด → พื้นที่ยกตัวขึ้น → ป้ายค่อยปรากฏ)
ระบบเคารพการตั้งค่า “ลดการเคลื่อนไหว” ของเครื่องผู้ใช้

**4. แก้ตามผลตรวจระบบทั้ง 15 ข้อ** — ดูรายละเอียดใน `CHANGELOG.md`

## วิธีติดตั้งทับของเดิม

1. **ติด tag รุ่นเดิมไว้ก่อน** เพื่อให้ย้อนกลับได้ถ้าไม่ถูกใจ
   ```bash
   git tag v4.0 && git push origin v4.0
   ```
2. อัปโหลดไฟล์ทั้งหมดในชุดนี้ทับ Repository `checkfile2568-ops/MapLibre`
3. **ลบไฟล์เก่าที่ไม่ใช้แล้ว** (สำคัญ ไม่ลบก็ไม่พัง แต่จะรกและชวนสับสน)
   - `styles.css` · `theme.css` · `view.css` · `overview.css` · `overview.js`
   - `ตัวอย่างนำเข้ายอด.csv` ที่ชื่อเพี้ยนอยู่ราก Repository
     (ย้ายไปเป็น `samples/price-import-example.csv` แล้ว)
   - `TEST_REPORT.md` · `MAP_VIEW_UPDATE_TEST_REPORT.md` (แทนที่ด้วย `tests/` ที่รันจริงได้)
4. เปิด `index.html` และ `view.html` ผ่าน GitHub Pages แล้วตรวจว่าแผนที่ขึ้นครบ
5. ถ้าเคยติ๊ก “จำรหัสไว้ในเครื่องนี้” ในรุ่นก่อน ระบบจะลบรหัสที่ค้างอยู่ให้อัตโนมัติ
   ครั้งแรกที่เปิดหน้าตั้งค่าระบบ จากนั้นวางรหัสใหม่ได้ตามปกติ

> **ข้อควรรู้** ระบบใหม่ **ไม่ต้องต่ออินเทอร์เน็ตออกนอกองค์กร** ก็เปิดใช้ได้
> เพราะขอบเขตแผนที่และไลบรารีทั้งหมดอยู่ใน Repository แล้ว
> จะต่อเน็ตก็เฉพาะตอนกดบันทึกขึ้น GitHub เท่านั้น

## ข้อมูลประชากรและครัวเรือน

ไฟล์ขอบเขตที่ให้มามีชื่อตำบล อำเภอ และจำนวนหมู่บ้านครบแล้ว แต่ยังไม่มีตัวเลข
ประชากร/ครัวเรือน (การ์ดข้อมูลตำบลจะขึ้นว่า “ไม่พบข้อมูล”)

ระบบจะไปขอจาก ArcGIS ให้เองแบบเบื้องหลังเมื่อเปิดหน้าเว็บ และเก็บไว้ในเครื่อง
ผู้ใช้ ถ้าอยากฝังตัวเลขลงไฟล์ถาวรเพื่อไม่ต้องพึ่งเน็ตเลย ให้รันครั้งเดียว

```bash
node tools/build-court-data.mjs --enrich
git add data/court-tambon.geojson && git commit -m "ฝังข้อมูลประชากรลงไฟล์ขอบเขต"
```

คำสั่งนี้จะดึงขอบเขตความละเอียดสูงพร้อมประชากรมาฝังไว้ในไฟล์เดียวกัน

## การบันทึกส่วนกลาง

- ใช้ Fine-grained token ที่จำกัดเฉพาะ Repository `MapLibre` สิทธิ์ `Contents: Read and write`
- รหัสถูกเก็บไว้ **เฉพาะแท็บที่เปิดอยู่** และหายไปเองเมื่อปิดเบราว์เซอร์
- การบันทึกหนึ่งครั้ง = **หนึ่ง commit** ที่มีทั้ง `assignments.json` และ
  `notice-area-sheet.csv` สำเร็จหรือล้มเหลวพร้อมกัน ไม่มีสภาพข้อมูลครึ่ง ๆ อีก
- ข้อความ commit สรุปให้เองว่าเปลี่ยนอะไรและใครเป็นคนบันทึก เช่น
  ```
  มอบหมายเพิ่ม 3 ตำบล · แก้ยอด 5 ตำบล

  ผู้บันทึก: checkfile2568-ops
  เวลา: 27 ส.ค. 2569 17:48
  ระบบ: เขตพื้นที่งานส่งหมาย v5.0.0
  ```
  ย้อนดูประวัติได้ที่หน้า Commits ของ Repository

## ความปลอดภัยและข้อมูลสาธารณะ

Repository และ GitHub Pages เป็นสาธารณะ การปิดสวิตช์ **แสดงยอดในหน้าจอแสดงผล**
ซ่อนยอดจากหน้าจอเท่านั้น ไฟล์ `data/assignments.json` ยังเปิดอ่านได้จาก GitHub
เสมอ หากวันใดยอดกลายเป็นข้อมูลภายใน ต้องย้ายไปไว้หลังระบบยืนยันตัวตน
(แนวทางที่เหมาะกับเครื่องมือเดิมคือ Google Apps Script Web App ถือ token ไว้ฝั่ง
เซิร์ฟเวอร์) — รายละเอียดอยู่ในรายงานตรวจระบบข้อ ตร-04 และ ตร-11

## จุดที่ต้องแก้เมื่อต้องการต่อยอด

| อยากทำอะไร | แก้ที่ไหน |
|---|---|
| เปลี่ยนสีหรือฟอนต์ | `tokens.css` ที่เดียว ทั้งสองธีม |
| เปลี่ยนหน้าตาแผนที่ ป้าย มุมกล้อง | `map-engine.js` + `map.css` |
| เพิ่ม/ลดอำเภอในเขตศาล | `COURT_AMPHOE_CODES` ใน `core.js` แล้วรัน `tools/build-court-data.mjs` |
| เพิ่มฟิลด์ใหม่ในข้อมูลกลาง | `initialState` + `normalizeState` + `serializableState` ใน `core.js` |
| ออกเลขรุ่นใหม่ | `APP_VERSION` ใน `core.js` และ `?v=` ในสอง HTML (ชุดทดสอบจะเตือนถ้าไม่ตรงกัน) |

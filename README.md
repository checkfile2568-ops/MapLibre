# ระบบบริหารเขตพื้นที่งานส่งหมาย — Version 4

ระบบ Static Web App สำหรับศาลจังหวัดลพบุรี รองรับการกำหนดผู้รับผิดชอบ เขตอำเภอ/ตำบล และยอดรายพื้นที่ที่แตกต่างกัน พร้อมหน้าดูผลแบบอ่านอย่างเดียว

## ความสามารถหลัก

- Migration ข้อมูลกลาง Version 3 เป็น Version 4 อัตโนมัติ โดยไม่ลบรายชื่อหรือการมอบหมายเดิม
- ใช้รหัสอำเภอ `ADMIN_ID2` เป็นหลัก และใช้ชื่ออำเภอเป็น fallback
- กำหนดผู้รับผิดชอบทั้งอำเภอ รายตำบล หรือคลิกบนแผนที่
- เพิ่ม แก้ชื่อ เปิด/ปิดใช้งาน โอนพื้นที่รายตำบล โอนทั้งหมด และป้องกันการลบผู้ที่ยังมีพื้นที่
- กำหนดยอดรายตำบลได้ไม่เท่ากัน รองรับเลขอารบิก เลขไทย เครื่องหมายคอมมา และทศนิยมไม่เกิน 2 ตำแหน่ง
- นำเข้ายอดจากข้อความ `.txt` หรือ `.csv`
- รูปแบบนำเข้าที่แนะนำ: `อำเภอ/ตำบล ยอด` เช่น `เมืองลพบุรี/ทะเลชุบศร 500`
- ตรวจจับชื่อตำบลซ้ำข้ามอำเภอ และขอให้ระบุชื่ออำเภอเมื่อข้อมูลกำกวม
- เปิด/ปิดป้ายยอดบนแผนที่หน้าจัดการ
- เปิด/ปิดการแสดงยอดในหน้า `view.html`
- หน้า View ค้นหาด้วยชื่อตำบล อำเภอ ผู้รับผิดชอบ หรือยอดได้
- รายงาน Excel และ PDF รวมยอดรายพื้นที่และยอดรวมรายบุคคล
- สำรอง/กู้คืน JSON, ดาวน์โหลด PNG และพิมพ์แผนที่ A4
- ตรวจ Fine-grained GitHub token และป้องกันการเขียนทับเมื่อไฟล์กลางเปลี่ยน
- เตือนก่อนออกจากหน้าหากยังไม่ได้บันทึกส่วนกลาง
- รองรับมือถือแนวตั้ง/แนวนอน และลดการแย่ง Gesture กับการเลื่อนหน้าบนจอสัมผัสแนวนอน

## โครงสร้างไฟล์

```text
index.html              หน้าจัดการ
styles.css              รูปแบบหน้าจัดการ
core.js                 กติกาข้อมูลร่วมและ Migration
app.js                  การทำงานหน้าจัดการ
view.html               หน้าดูผล
view.css                รูปแบบหน้าดูผล
view.js                 การทำงานหน้าดูผล
data/assignments.json   ข้อมูลกลาง Version 4
tests/                  ชุดทดสอบ
TEST_REPORT.md          รายงานผลทดสอบ
```

## วิธีอัปเดต GitHub

1. สำรอง Repository เดิมหรือดาวน์โหลด ZIP ของ Branch `main`
2. อัปโหลดไฟล์ทั้งหมดจากชุดนี้ทับไฟล์เดิม
3. ตรวจว่า `core.js` อยู่ที่ Root เดียวกับ `index.html`
4. ตรวจว่า `data/assignments.json` อยู่ในโฟลเดอร์ `data`
5. เปิด GitHub Pages แล้วทดสอบ `index.html` และ `view.html`
6. กำหนดยอดจริงในหน้าจัดการ จากนั้นกด **บันทึกส่วนกลาง**

## การนำเข้ายอด

ตัวอย่างที่แนะนำ:

```text
เมืองลพบุรี/ทะเลชุบศร 500
พัฒนานิคม/พัฒนานิคม 650.50
ท่าวุ้ง/บางคู้ ๗๕๐
```

กรณีชื่อตำบลซ้ำ เช่น `บางคู้` ให้ระบุอำเภอเสมอ

## ความปลอดภัยและข้อมูลสาธารณะ

Repository และ GitHub Pages ปัจจุบันเป็นสาธารณะ การปิดตัวเลือก **แสดงยอดในหน้าดูผลสาธารณะ** จะซ่อนยอดจาก UI เท่านั้น แต่ข้อมูลใน `data/assignments.json` ยังเปิดอ่านได้จาก GitHub หากยอดเป็นข้อมูลภายในหรือลับ ควรย้ายข้อมูลไป Backend ที่มีการยืนยันตัวตน

Fine-grained token ควรจำกัดเฉพาะ Repository `MapLibre` และให้สิทธิ์เฉพาะ `Contents: Read and write` ไม่ควรจำ Token บนเครื่องที่ใช้ร่วมกัน

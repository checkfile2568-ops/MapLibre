# ระบบบริหารเขตพื้นที่งานส่งหมาย — ศาลจังหวัดลพบุรี

เว็บแอปสำหรับกำหนดเขตความรับผิดชอบงานส่งหมายตามอำเภอและตำบลในจังหวัดลพบุรี พร้อมแผนที่แบบ 3D และการส่งออกเป็นภาพ PNG

## ความสามารถ

- เพิ่มชื่อผู้รับผิดชอบ หรือนำเข้าจากไฟล์ `.csv` / `.txt`
- คละสีให้โดยอัตโนมัติ และตรวจสีซ้ำหรือสีที่ใกล้กันเกินไป
- เลือกทั้งอำเภอ หรือเลือกรายตำบล รวมถึงเลือกข้ามอำเภอได้
- ป้องกันการมอบหมายตำบลซ้ำ: การย้ายพื้นที่จะแสดงคำยืนยัน
- แผนที่หลักแสดง 6 อำเภอในเขตศาลจังหวัดลพบุรีแบบสีเต็มและนูน 3D
- แผนที่ย่อแสดง 5 อำเภอในเขตศาลจังหวัดชัยบาดาล: ชัยบาดาล, ท่าหลวง, สระโบสถ์, โคกเจริญ และลำสนธิ โดยยังเลือกมอบหมายได้ แต่ใช้สีจาง
- แสดงหรือซ่อนชื่อตำบลบนแผนที่หลัก
- ดาวน์โหลดภาพสรุปเป็น PNG
- สำรองและกู้คืนรายชื่อ/การมอบหมายด้วย JSON
- อ่านข้อมูลกลางอัตโนมัติเมื่อเปิดเว็บ จึงเห็นข้อมูลชุดเดียวกันทุกเครื่อง
- บันทึกข้อมูลกลางกลับไปที่ GitHub อย่างปลอดภัย โดยไม่เก็บรหัสบันทึกไว้ในเบราว์เซอร์
- รองรับโทรศัพท์ทั้งแนวตั้งและแนวนอน

## การเปิดใช้งาน

เป็นเว็บแบบ static จึงเปิดผ่าน GitHub Pages ได้ทันทีหลังเปิดใช้งาน Pages ของรีโพซิทอรี หรือใช้เว็บเซิร์ฟเวอร์ในเครื่อง ตัวอย่างเช่น:

```powershell
python -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080`

การโหลดครั้งแรกต้องเชื่อมต่ออินเทอร์เน็ต เพราะระบบเรียกขอบเขตตำบลจริงของจังหวัดลพบุรีจาก ArcGIS Feature Service แบบอ่านอย่างเดียว

## การใช้ข้อมูลร่วมทุกเครื่อง

เมื่อเปิดเว็บ ระบบจะอ่านการมอบหมายล่าสุดจากไฟล์กลาง `data/assignments.json` ใน GitHub โดยอัตโนมัติ ทุกเครื่องจึงเห็นข้อมูลชุดเดียวกัน

ผู้ที่มีสิทธิ์แก้ไขทำตามนี้:

1. สร้าง **Fine-grained personal access token** ของ GitHub สำหรับรีโพซิทอรี `checkfile2568-ops/MapLibre` และกำหนด Repository permissions > **Contents: Read and write**
2. แก้ไขเขตงานตามปกติ
3. วาง token ในช่อง **รหัสบันทึก GitHub** แล้วกด **บันทึกส่วนกลาง**

ระบบใช้ token เฉพาะตอนกดบันทึกและล้างออกทันทีหลังสำเร็จ โดยไม่เก็บไว้ในเบราว์เซอร์ หากมีคนอื่นบันทึกข้อมูลก่อน ระบบจะแจ้งให้โหลดข้อมูลกลางใหม่ก่อน เพื่อป้องกันการเขียนทับโดยไม่ตั้งใจ

## ข้อมูลขอบเขต

ระบบใช้ชุดข้อมูล [Thailand Subdistrict Boundaries 2025](https://www.arcgis.com/home/item.html?id=8cb398a471dc4220984e9287df03c317) ของ NOSTRA / MERKATOR ผ่าน ArcGIS Feature Service และเลือกเฉพาะรหัสจังหวัดลพบุรี `16` ข้อมูลการมอบหมายผู้รับผิดชอบไม่ถูกส่งไปยังบริการดังกล่าว

## ข้อควรใช้ในงานจริง

- ควรกด **สำรองข้อมูล** เป็นระยะ แม้ข้อมูลกลางจะบันทึกไว้แล้ว
- รีโพซิทอรีนี้เป็นแบบสาธารณะ ดังนั้นไฟล์การมอบหมายส่วนกลางจะเปิดอ่านได้ตามการตั้งค่า GitHub ปัจจุบัน ไม่ควรใส่ข้อมูลส่วนบุคคลหรือข้อมูลลับลงในระบบนี้
- ก่อนประกาศใช้อย่างเป็นทางการ ควรตรวจสอบขอบเขตอำนาจศาลกับคำสั่งหรือข้อมูลทางราชการล่าสุดของหน่วยงานอีกครั้ง
- ผู้ที่ไม่มี token เปิดดูแผนที่และข้อมูลล่าสุดได้ แต่ไม่สามารถบันทึกแก้ไขข้อมูลกลางได้
